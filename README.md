# PPA ANAC 95+ — V11 Learning Academy

Aplicação de aprendizagem PPA/VFR, sem integração com X-Plane ou qualquer simulador externo.

Inclui protocolo 95%+, matérias/capítulos, simulados, radionavegação VOR/NDB, navegação noturna/ILS didática, METEO, cartas, FPL, peso e balanceamento, briefing, NavLog, mapa de competência, treinador visual, missões, ATC/fonia didática, emergências/ADM, INVA virtual, biblioteca local, backup, Flight Pack e diagnóstico.

Limites: serviços online dependem das fontes externas/publicação; conteúdo de todos os PDFs ainda não está integralmente indexado; reconhecimento de voz depende do navegador; dados operacionais devem ser confirmados nas fontes vigentes.
