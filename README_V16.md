# PPA ANAC 95+ — V16 Fonte Externa Aerodinâmica

Continua a V15 e adiciona um banco externo de Aerodinâmica analisado a partir da página Hangar MMA informada pelo usuário.

## Classificação
- Matéria PPA: **TV — Teoria de Voo**.
- Temas: aerofólio, cambra, corda, sustentação, arrasto, L/D, ângulo de ataque, eixos, comandos primários, compensadores, glissagem/derrapagem e dispositivos hipersustentadores.
- A própria página-fonte é direcionada à banca de **Mecânico de Manutenção Aeronáutica (MMA)**, não especificamente ao PPA.

## Integração segura no PPA
- 22 questões novas, redigidas originalmente a partir dos conceitos compatíveis com PPA.
- Itens específicos de helicóptero, manutenção de MMA e alta velocidade não entram no banco PPA padrão.
- A aplicação não rotula a fonte como banco oficial ANAC; guarda a proveniência como fonte externa.
- O filtro global de repetição continua ativo.
- Perfis Jorge/Cândido e progresso anterior são preservados (mesmas chaves de progresso da V15).
